01

先纠正三个常见误解

搞错这三件事，就会一直觉得"这玩意儿跟我没关系"

它不是网盘

网盘只存文件。GitHub 每存一次都留档——哪天你手滑改坏了，能一秒回到三天前的版本。聊天记录、Excel、脚本都行。

它不是编辑器

它不写代码。它是代码和文件的存放地 + 改动记录本。你用现有的工具写，GitHub 负责存、管、备份。

它是"能自动干活的服务器"

提交上去之后，可以让它自动定时跑脚本、自动把网页发布成链接。这部分完全免费，是很多人不知道的隐藏用法。

对你来说，6 件真正能用的事

不是通用功能列表，是按你的实际工作筛出来的

最实用

给 HTML 报告发一个链接

你做的那些 HTML 报告、培训材料，本来只能打包发文件。用 GitHub Pages 传上去，会得到一个 https://xiongkun2026.github.io/xxx/ 的网址，微信直接发，同事点开就能看，不用装任何东西。

最实用

AI 编程工具的门票

Claude Code、Codex、Copilot 这类工具，都要用 GitHub 账号登录。你刚注册的这个号，就是它们的入场券。已有账号的话很多工具也能直接挂上来。

强烈建议

多轮迭代的东西，有个版本账本

你那些带版本号的交付物（工具 v1.0.0、报告改到第 4 版），每次迭代存一版。客户说"要回上一版"，你不用回忆，直接下载。

日常

工具的正规出处

网上教程说"去 GitHub 下载源码"，指的就是这里。下载前先看 Star 数和最近更新时间，能避开大部分已经废弃的项目。

进阶

定时自动跑任务

Actions 能让你设定的脚本每天凌晨自动执行——比如自动汇总数据、自动更新报表。免费版每月 2000 分钟，够用。

注意

公司代码，别擅自往这儿放

哪怕是私有库（Private），代码也是出境到境外平台。这事得 IT / 法务点头，个人账号扛不住这个责任。先确认，再上传。

04

界面全英文，怎么办

GitHub 没有官方中文界面，但有现成解法

Chrome 一键翻译

地址栏右侧会出现 翻译 按钮，点一下整站变中文。设置 → 始终翻译英文，以后到 GitHub 自动翻译。

装「沉浸式翻译」插件

Chrome 商店搜 沉浸式翻译。效果比自带翻译好，段落不丢格式，还能整页对照原文。这是最推荐的方案。

现在做这三步，之后就不用管了

全程本地，不上传任何东西

1

双击运行初始化脚本

在 GitHub账号初始化/ 文件夹里双击 一键配置.command。它会生成 SSH 密钥、写入 SSH 配置、设置 Git 提交身份。终端里会打印你的公钥。

2

把公钥贴到 GitHub

浏览器打开 https://github.com/settings/ssh/new，Title 填 MacBook Pro，Key 粘贴脚本打印的那一整行，点 Add SSH key。

# 要粘贴的就是这一整行：
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIJk5SlSQInSklF7MFaMnZzDZ/YvIK6w5iMri2Zo9NgNk xiongkun2026@users.noreply.github.com
3

验证连通

终端执行下面这行，看到欢迎语就成功了。

ssh -T git@github.com
# 期望输出：
Hi xiongkun2026! You've successfully authenticated, but GitHub does not provide shell access.
